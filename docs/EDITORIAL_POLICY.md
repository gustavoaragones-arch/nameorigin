# Editorial Policy

_Editorial principles and methodology for NameOrigin.io._

## Editorial principles

1. **Research-backed entries** — Meanings, origins, and related domains derive from established references, not invented content.
2. **Disclosed unknown** — When data is unavailable, pages state that clearly rather than implying certainty.
3. **Deterministic editorial QA** — Records pass consistency audits before contributing to scoring or presentation.
4. **Architecture preservation** — Presentation and trust phases never modify editorial records.

## Confidence methodology

Confidence reflects verified editorial coverage and supporting citations. KCI summarizes completeness across editorial, citation, and popularity dimensions without replacing editorial judgment.

## Citation philosophy

Citations connect editorial claims to canonical publications. The Citation Registry normalizes reference variants so the same publication is never duplicated under multiple aliases.

## Popularity methodology

Popularity data comes from authoritative national and regional datasets where available. Source attribution uses canonical Popularity Registry IDs internally; users see countries, years, and availability — not raw authority strings or internal identifiers.

## Data preservation policy

| Layer | Policy |
| --- | --- |
| Knowledge Records | Frozen during presentation phases |
| Citation Records | Frozen after population |
| Popularity Records | Frozen after population |
| KCI weights | Frozen after activation |

Updates occur through explicit architectural milestones, not ad hoc page edits.

## Deterministic generation philosophy

All public pages are statically generated from audited data artifacts. The build pipeline is repeatable and verifiable through equivalence and rebuild audits.

## Future update process

1. Complete infrastructure phase (engine only)
2. Complete population phase (data only)
3. Run validation, editorial QA, and equivalence
4. Activate or expose through presentation layers
5. Document milestone in architecture version history

No phase modifies previously frozen layers without an explicit new milestone.
