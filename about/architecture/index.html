Architecture

Sources & Methodology · Editorial Policy · Architecture · Quality Assurance

Frozen architecture milestones for Knowledge, Citation, Popularity, KCI, and presentation layers with validation and equivalence status.

The platform architecture follows a strict layering model. Each milestone completes with validation, equivalence, and audit artifacts before the next milestone begins. This prevents presentation work from silently modifying editorial or scoring data.

Milestone Summaries

  • Knowledge Architecture (v2) — Structured editorial knowledge records across origin, meaning, pronunciation, etymology, and history. Status: Frozen.
  • Citation Infrastructure (v1) — Canonical publication registry with deterministic normalization and resolution. Status: Frozen.
  • Citation Population (v1) — Entity-level citation assignments mapped to canonical publication IDs. Status: Frozen.
  • Popularity Infrastructure (v1) — Canonical popularity source registry with authority normalization. Status: Frozen.
  • Popularity Population (v1) — Entity-level popularity records with canonical source attribution. Status: Frozen.
  • KCI Activation (v1) — Deterministic Knowledge Completeness Index consuming Citation and Popularity records. Status: Frozen.
  • KCI Explainability (v1) — Read-only presentation of KCI component scores on name pages. Status: Frozen.

Layering Model

  1. Knowledge — editorial source of truth
  2. Citation — canonical publication attribution
  3. Popularity — normalized source attribution
  4. KCI — deterministic scoring engine
  5. Presentation — read-only user exposure
  6. Trust — transparency and methodology pages

Compatibility

Frozen layers remain readable by all higher layers but are never mutated by them. Citation Infrastructure and Popularity Infrastructure were completed before their respective population phases, mirroring the Knowledge Record pattern established earlier in the project.

Version Presentation

Every architecture milestone displays a version label, frozen status, and PASS validation and equivalence badges where applicable. These values are derived from audit artifacts rather than hand-maintained page copy. Review the quality assurance page for the latest validation summary.
